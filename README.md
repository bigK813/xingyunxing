# 🦍 幸运猩 — 体彩智能预测系统 v2.0

"用数据说话，不凭感觉下注"

## 支持彩票

| 彩票 | 规则 | 历史数据 |
|---|---|---|
| 🔴🔵 大乐透 | 前区 35选5 + 后区 12选2 | ~2,900 期 (2007-) |
| ⭐ 七星彩 | 7位数字 (0-9 / 末位 0-14) | ~3,400 期 (2004-) |
| 🎲 排列5 | 5位数字 (0-9) | ~7,700 期 (2004-) |

## 启动

```bash
python3 -m streamlit run app.py
```

浏览器自动打开 http://localhost:8501

## 预测算法

| 算法 | 说明 | 适用彩票 |
|---|---|---|
| 频次分析 | 历史出现次数，热号加权 | 全部 |
| 遗漏回补 | 长时间未出号码的回归概率 | 全部 |
| 位频分析 | 每个位置的独立频次统计 | 七星彩/排列5 |
| 和值趋势 | 前区5个红球之和接近历史均值 | 大乐透 |
| 奇偶匹配 | 奇偶比匹配历史最常见模式 | 大乐透 |
| 大小匹配 | 大小号分布匹配历史 | 大乐透 |
| 区间覆盖 | 5个红球分散在不同区间 | 大乐透 |
| 连号匹配 | 根据历史连号概率决定 | 大乐透 |

蒙特卡洛模拟在约束条件下加权抽样，按综合得分排序输出 Top N。

## 数据源

体彩官方 API: `webapi.sporttery.cn`

⚠️ 彩票号码随机，预测仅供娱乐参考，理性购彩。
